Five-minute judge path

  1. The app opens on Solana devnet. For the simulation, select Demo mode and choose Get started.
  2. Propose a YES / NO question. Set the funding goal, window and trading duration.
  3. Enter an HTTPS evidence source and clear YES / NO settlement rules.
  4. Commit simulated USDC, reviewing the amount before confirming.
  5. Expand Test the full journey and close the demo funding window.
  6. If the target was reached, launch and claim LP shares. Otherwise, claim your refund.
  7. Switch the network selector to Solana devnet to inspect the real integration, kept separate from demo data.

What is actually onchain?

In devnet mode, Clique calls PREDICT's commitment-vault program through its SDK. Creation includes a signed memo containing the source and settlement rules. Readers verify the original creation transaction, rather than trusting editable browser metadata.

Verified on Solana devnet: Create, YES/NO commit, launch, LP claim and refund all passed on 17 November 2026. All eight transaction receipts confirmed without errors. Account-state checks verified LP shares, returned funds and creator-signed rules. All 23 tests, the build and the 1,003-byte transaction-size check pass. These are developer tests, not user traction. Optional mainnet

Devnet remains the default and the network used for the published live receipts. Mainnet uses real USDC and Phantom wallet approval, with separate datasets and no browser test key or faucet. Mainnet reads and mocked signing checks passed; no real mainnet transaction was sent or verified. This release has not received an independent security audit.

Know the scope

Committers become liquidity providers, not direct holders of YES / NO outcome tokens. LP value can fall. Resolution is creator-controlled; signed rules do not add an oracle or dispute process. Launch is manually triggered, and this version ends at LP claims.
